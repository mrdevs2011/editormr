# EMR VideoEditor

Brauzerda ishlaydigan video-editor (EditorMR - VideoEditor).

## Ishga tushirish

1. Supabase loyiha oching, Google Auth yoqing.
2. Vercel env: `SUPABASE_URL`, `SUPABASE_ANON_KEY`
3. Deploy yoki local: static server + COOP/COEP header

- `js/` — ilova kodi
- `css/` — stillar
- `render/` — canvas renderer
- `tests/` — Node testlar
